# Project Introduction

This capstone requires students to design and develop a responsive Airline Booking System website that demonstrates their understanding of modern frontend web development principles. Students are expected to apply HTML for semantic page structure, CSS for styling, and Bootstrap for responsive layouts and reusable user interface components.

The project simulates a real-world airline website where users can browse available flights, view flight information, complete a booking form, and learn more about the airline. Although the website resembles a functional booking platform, all content is static and intended solely to demonstrate frontend development skills.

This capstone assesses students' ability to independently integrate the knowledge acquired throughout the module into a cohesive, well-organized, and visually consistent website.

---

# Assessment Focus

This capstone evaluates the student's ability to:

* Create semantic HTML page structures.
* Apply CSS to produce consistent and visually appealing designs.
* Utilize Bootstrap components appropriately.
* Build responsive layouts using the Bootstrap Grid System.
* Organize a multi-page website with functional navigation.
* Design user-friendly forms using Bootstrap.
* Maintain consistent branding across multiple webpages.
* Produce clean, organized, and maintainable frontend code.

# Facilitation Guide

During the capstone, instructors should:

## Introduce the Project

* Explain the business scenario and overall project objective.
* Review the required pages, features, and submission requirements.
* Clarify that the project is a frontend-only implementation.

## Clarify Requirements

* Answer questions regarding the project specification.
* Clarify expected outputs and project scope.
* Reinforce the defined project constraints.

## Supporting Students

When students request assistance:

* Clarify the requirement without explaining how to implement it.
* Encourage students to reference previous module materials.
* Ask guiding questions that help students analyze the problem independently.
* Avoid demonstrating code or providing implementation examples.

## Monitoring Progress

Observe whether students are:

* Building all required pages.
* Applying Bootstrap components appropriately.
* Maintaining responsive layouts.
* Following consistent branding.
* Organizing project files properly.

## Redirecting Struggling Students

If students become stuck:

* Refer them back to the project specification.
* Encourage them to divide the project into smaller tasks.
* Remind them to prioritize required features before optional enhancements.

# Common Student Difficulties

| Common Issue                        | Recommended Instructor Response                                                                        |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------ |
| Missing required pages              | Remind students to review the Required Pages section of the specification.                             |
| Broken navigation links             | Encourage students to verify file names and relative paths.                                            |
| Inconsistent branding               | Ask students to compare typography, colors, logos, and styling across pages.                           |
| Layout breaks on smaller screens    | Encourage students to revisit Bootstrap Grid classes and responsive utilities.                         |
| Incorrect Bootstrap component usage | Direct students to consult the Bootstrap documentation without demonstrating implementation.           |
| Poor project organization           | Remind students to organize files into appropriate folders and maintain consistent naming conventions. |

---

# Evaluation Notes

When reviewing submissions:

* Verify that every required page has been implemented.
* Confirm that navigation functions correctly throughout the website.
* Ensure Bootstrap components are used appropriately.
* Verify that the website is responsive on multiple screen sizes.
* Check that branding remains consistent across all pages.
* Confirm that all required deliverables have been submitted.
* Identify missing pages, broken links, missing assets, or incomplete sections before final evaluation.
